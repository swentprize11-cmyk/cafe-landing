# cafe-landing

가상의 동네 카페 "모닝브루"의 간단한 랜딩 페이지입니다. 순수 HTML/CSS로만 만들어져 별도의 빌드나 설치 없이 바로 열어볼 수 있습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (상단 메뉴, 메인 소개, 대표 메뉴, 카페 소개, 오시는 길, 푸터) |
| `style.css` | 스타일 (커피 색상 테마, 모바일 대응 반응형 레이아웃) |

## 사용 방법

`index.html` 파일을 브라우저로 열면 됩니다.

## 참고

- 카페 이름, 메뉴 가격, 주소, 전화번호는 예시 내용입니다. 실제 정보로 바꿔서 사용하세요.
